# insurance-management-system-221010-221022

Backend (Django REST Framework) with PostgreSQL.

- Environment variables in `backend/.env.example`. Copy to `.env` and fill values.
- API base path: `/api/`
  - `/api/customers/`
  - `/api/policies/`
  - `/api/claims/`
  - `/api/health/`
- Swagger UI: `/docs`
- Redoc: `/redoc`
- OpenAPI JSON: `/swagger.json`
